CastPilot

YouTube 채널 「말이 되는 영어」 제작 도구

CastPilot은 YouTube 채널 「말이 되는 영어」를 운영하기 위해 만든 개인용 영상 제작 도구입니다. 매일 한 가지 상황의 영어 표현을 정리하고, 사람이 직접 검수한 뒤 학습 영상(한국어 한 번, 영어 네 번 반복)을 만들어 채널 운영자 본인의 YouTube 채널에 업로드합니다.

하는 일

  • 영어 표현 목록 작성과 운영자 검수
  • 음성·자막·썸네일이 포함된 학습 영상 제작
  • 운영자 본인 채널에 영상·썸네일·자막 업로드 (YouTube Data API)
▶ YouTube
이 도구는 YouTube API 서비스를 사용합니다 (This app uses YouTube API Services).
채널: 말이 되는 영어 (@malidoenun.english) · YouTube 서비스 약관 · Google 개인정보처리방침

이 도구는 채널 운영자 한 사람만 사용하며, 다른 사용자의 계정이나 데이터에 접근하지 않습니다.

English

CastPilot is a personal tool used only by the owner of the YouTube channel “말이 되는 영어” (Mal-i Doeneun English) to produce English-learning videos and upload them, with their thumbnails and captions, to the owner’s own channel via the YouTube Data API.
