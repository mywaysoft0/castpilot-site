개인정보처리방침

CastPilot · 시행일 2026-11-26

1. 사용하는 Google 데이터

CastPilot은 채널 운영자 본인의 Google 계정으로 아래 YouTube 권한만 요청합니다.

  • youtube.upload: 운영자 본인 채널에 영상 업로드
  • youtube.force-ssl: 업로드한 영상의 썸네일·자막 등록, 공개 상태 변경, 재생목록 추가

다른 사용자의 데이터, 시청 기록, 구독자 정보, 연락처, 이메일 내용은 읽거나 수집하지 않습니다.

2. 저장과 보관

인증 토큰(refresh token)은 운영자 개인 컴퓨터에만 저장하며 외부 서버로 보내지 않습니다. 영상 파일과 작업 기록도 운영자 개인 컴퓨터에만 보관합니다.

3. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 제공·공유하지 않으며, 광고나 다른 목적으로 사용하지 않습니다. CastPilot이 Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(Limited Use 요건 포함)을 따릅니다.

4. 권한 철회와 삭제

언제든지 Google 계정 → 보안 → 타사 액세스에서 CastPilot의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없으며, 운영자 컴퓨터에서도 삭제합니다.

5. 데이터 삭제 정책 (Data deletion)

권한을 철회하거나 삭제를 요청하면, CastPilot이 저장한 인증 토큰과 YouTube 관련 데이터(업로드한 영상의 ID·URL)를 7일 이내에 운영자 컴퓨터에서 삭제합니다. CastPilot은 YouTube API로 받은 데이터를 30일 넘게 새로 고치지 않은 채 보관하지 않습니다.

6. YouTube 서비스 약관

CastPilot은 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

7. 문의

YouTube 채널 「말이 되는 영어」 정보 페이지를 통해 문의할 수 있습니다.

English summary

CastPilot only requests YouTube upload and caption/thumbnail management scopes for the channel owner’s own account. Tokens are stored only on the owner’s personal computer. No Google user data is sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions; on revocation or a deletion request, stored tokens and YouTube data (IDs/URLs of uploaded videos) are deleted within 7 days. CastPilot uses YouTube API Services; the YouTube Terms of Service and Google Privacy Policy apply.
